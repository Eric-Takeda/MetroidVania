<p>
  Objetivo: Explorar engines de jogos...
</p>
<p>Foi utilizado:</p>
<p>4 Rooms;</p>
<p> 52 Sprites;</p>
<p>14 Objetos;</p>
<p>3 Scripts;</p>
<p>2 tipos de fontes;</p>
<p>1 Curva de animação;</p>
<p></p>

<p>O jogo contém:</p>
<p>1 Player jogável;</p>
<p>3 tipos de inimigos;</p>
<p>2 cenários;</p>
<p>Uma tela de menu e uma de Game Over;</p>
<p></p>

<p>Comandos:</p>
<p>Setas direcionais navegam pelo menu - ⬆️⬇️</p>
<p>Enter seleciona a opção que está por cima - ↵</p>
<p>Enter no jogo volta ao menu - ↵</p>
<p>Tecla "K" faz o pulo</p>
<p>Tecla "A" movimento o player para a esquerda</p>
<p>Tecla "D" movimento o player para a direita</p>
<p>Tecla "J" realiza o ataque</p>
<p>Tecla "L" realiza o Dash</p>
<p>Tecla "J" + no Ar realiza ataque áereo</p>
<p>Tecla "J" + no Ar + S realizado o ataque para baixo</p>
<p>Tecla "J" + "J" + "J" realiza um combo</p>
<p>Tecla "L" + no Ar realiza o Dash Aéreo</p>
<p>Tecla Direcional + no Ar + na Parede desliza na parede</p>
<p>Tecla "Espaço" em cima da porta realiza a transição de salas</p>
